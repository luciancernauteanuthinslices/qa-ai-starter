## 🚨 Pattern Recognition

### Historical Learning Patterns Applied
1. **Syntax Fragility**: `:has-text()` selectors consistently break
2. **Attribute Dependency**: Over-reliance on CSS classes
3. **Semantic Gap**: Minimal accessibility considerations

## 🛡️ Prevention Guidelines

### Locator Creation Best Practices
- Always add `data-testid` attributes in application code
- Prioritize semantic HTML roles
- Use exact text matching
- Implement fallback locator strategies
- Avoid index-based or complex XPath selections

### Recommended Workflow
```typescript
// Ideal Locator Implementation
function createRobustLocator(page, options = {}) {
  return page.getByTestId(options.testId)
    .or(page.getByRole(options.role, { name: options.name }))
    .or(page.getByText(options.text, { exact: true }))
    .first();
}
```

## 💡 Key Takeaways

1. **Stability**: Prioritize `data-testid` and semantic roles
2. **Accessibility**: Use `getByRole()` with precise naming
3. **Flexibility**: Implement multi-strategy locator selection
4. **Maintainability**: Decouple tests from UI implementation details
